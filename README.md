# PlugLayer for Google Antigravity

This plugin connects Google Antigravity to PlugLayer through the hosted MCP service. No Python, uv, Node, Docker, Git, terminal command, or PlugLayer desktop app is required.

## Setup

1. Open **Setup** in the PlugLayer portal.
2. Choose Antigravity and copy the prompt.
3. Paste it into Antigravity.
4. Sign in and approve PlugLayer OAuth in the browser.

Antigravity stores the OAuth connection securely and refreshes it when needed. Never copy an API token into chat. The hosted MCP URL is `https://mcp.pluglayer.com/mcp`.

The plugin includes PlugLayer MCP plus deployment, repo inspection, domains, CI/CD, project metadata, environment updates, feedback, security, and repair skills.
